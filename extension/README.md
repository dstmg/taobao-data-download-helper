# 淘宝商家数据下载助手

当前版本：1.2.3（下载记录隐私优化）。用户已反馈淘宝联盟单日下载与历史补采可用。不同账号、电脑和官方页面版本可能存在差异，不保证免风控或无人值守。

1.2.3仅保留插件任务识别出的最近下载记录（最多30条），不保存完整下载URL；清空旧版宽范围记录，不删除下载文件或配置。现有权限保留。包含专属图标，完整更新插件目录后重新加载即可，无须卸载。详见隐私说明.md。

下载完成识别兼容官方原始CSV文件名；若缺少下载来源信息，需核实同商家页面对应官方任务已完成，不能仅凭文件名判断成功。正常完成或超时后释放任务占用，不自动重复提交。

面向普通淘宝商家的 Chrome / Edge 本地扩展。它在已登录的官方页面中模拟人工操作，调用页面自带的导出功能，把报表下载到本机。

## 支持的数据

- 生意参谋：店铺经营核心日报、商品数据
- 阿里妈妈：营销场景报表、商品推广报表、内容推广明细
- 淘宝联盟商家端：店铺整体数据—推广概览，默认分天、按计划/活动类型，官方CSV；不含CPS订单明细、热浪或抖客
- 自选日期范围（单次最多 31 天）
- 每日定时采集、暂停与恢复、运行日志
- 按日期逐日历史补采

## 隐私与权限

独立版不连接工作台、局域网服务器、钉钉或第三方 ERP，也没有设备编号和令牌。运行时只请求淘宝、生意参谋和阿里妈妈域名权限。数据文件由浏览器直接保存到本机下载目录，扩展不会把报表上传到其他服务。

## 安装

1. 解压交付包，保留完整文件夹。
2. Chrome 打开 `chrome://extensions/`；Edge 打开 `edge://extensions/`。
3. 开启“开发者模式”。
4. 点击“加载已解压的扩展程序”，选择本文件夹。
5. 固定工具栏上的“淘宝商家数据下载助手”。

升级时：优先在原插件目录中备份后更新完整文件，再点扩展卡片的重新加载；若改从新目录加载，会成为另一个扩展，原设置不会自动迁移。请先停用旧插件，避免两份定时任务同时运行，不要先卸载丢失设置。此包不自动安装、不自动开启定时。

## 淘宝联盟首次验收

1. 手动登录 https://ad.alimama.com/ 的卖家账号，确认目标店铺，进入数据分析—推广概览。
2. 插件填写用于文件夹命名的店铺名称；它不会凭这个名称替你切换或验证目标店铺，运行前务必人工核对。
3. 选择昨天或更早的短日期，点击“淘宝联盟推广概览”。插件打开官方下载弹窗，使用只读日历选日期，核对分天及按计划/活动类型，再提交。
4. 保持页面和弹窗打开，等待官方生成及自动下载，最长等待3分钟。不确定结果时查看官方下载记录，不反复提交。
5. 核对CSV的日期、数据内容与官方页面一致。先验收单日，再验收跨月区间，最后考虑历史补采和定时。

新报表默认不参加定时；新安装默认关闭定时，原来显式保存为开启的设置保持。勾选后保存才会加入推广报表时段。平台提示昨日数据预计上午11点更新，建议之后运行。遇到登录、验证码、频控或无法确认日期时会报错，不尝试绕过。

淘宝联盟单次日期最多31天；平台页面提示保留最近400天、单次查询90天，插件采用更保守的31天限制。报表结果保留30天是官方下载记录保留期，不是历史数据查询期。当前不自动领取旧任务，不删除官方任务。

## 首次使用

1. 分别登录淘宝卖家中心、生意参谋和阿里妈妈。
2. 点击扩展，填写店铺名称；该名称只用于下载目录命名。
3. 选择昨天或更早的日期。
4. 第一次建议逐项下载一天，确认官方页面结构与账号权限正常。

## 历史补采说明

独立版没有外部数据库，因此无法知道过去已经下载过哪些日期。历史补采会按你选择的日期和报表类型重新执行官方导出。为降低账号风控和误操作风险，单次最多 31 天，并在日期之间保留等待间隔。

## 定时采集限制

- 浏览器和电脑需要处于运行状态，相关账号需要保持登录。
- 上午时段执行生意参谋报表，下午时段执行推广报表。
- 页面改版、登录失效、账号无报表权限时会在日志中显示失败原因。
- 扩展不会绕过验证码、登录验证或平台权限。

## 下载位置

文件由浏览器保存到默认下载目录，并按“店铺名称 / 报表类型 / 日期”组织。可在浏览器下载记录中查看实际位置。
