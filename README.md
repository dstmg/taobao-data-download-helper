## 能下载什么

| 后台 | 报表 |
| --- | --- |
| 生意参谋 | 店铺经营日报、商品数据 |
| 阿里妈妈 | 营销场景、商品推广、内容推广明细 |
| 淘宝联盟商家端 | 店铺整体数据 → 推广概览（分天＋按计划/活动类型） |

支持自选日期、按日期逐日历史补采、每日定时、暂停和运行日志。单次历史补采最多31天。淘宝联盟这里指**商家推广概览**，不是CPS订单明细，也不包含热浪、抖客。

## 安装只需几步

1. 在右侧 **Releases** 下载 `taobao-data-download-helper-v1.2.3.zip`，解压到固定文件夹。不需要安装Node或Python。
2. Chrome打开 `chrome://extensions/`，Edge打开 `edge://extensions/`。
3. 开启“开发者模式”，点击“加载已解压的扩展程序”。
4. 选择解压后**包含manifest.json的文件夹**，在浏览器工具栏固定插件。
5. 分别手动登录需要使用的官方后台，核对当前店铺后使用。

如果通过绿色Code按钮下载源码ZIP，请选择其中的 **extension** 文件夹加载，而不是仓库根目录。

## 第一次下载

1. 填写店铺名称，供下载文件夹命名使用。这个名称不会自动切换账号，操作前请核对后台店铺。
2. 选择昨天或更早的日期，点击对应报表按钮。
3. 保持官方页面打开，等待平台生成和浏览器下载。淘宝联盟可能需要等待约3分钟。
4. 文件保存到浏览器默认下载目录；可在浏览器下载记录中查看实际位置。

建议先下载单日，确认结果后再补采多日。历史补采会重新提交所选日期，不会根据本机文件自动跳过。不要重复点击尚在运行的任务。

## 每日定时

新安装默认关闭定时。按需勾选报表、设置时间并保存：上午时段执行生意参谋，下午时段执行推广报表。淘宝联盟默认不勾选。

电脑、浏览器需要运行，账号需要保持登录；关闭浏览器后不会后台代跑。淘宝联盟昨日数据可能上午11点后才更新，建议之后运行。登录失效、验证码和频控需要人工处理，插件不绕过验证或平台权限。

## 更新已有插件

先备份当前插件目录，再将新包全部文件（包括icons文件夹）更新到原目录，最后在扩展管理页点击“重新加载”。不要先卸载，以免丢失本地设置。

从不同目录重新加载可能成为另一份扩展。避免同时运行两份插件的定时任务。本项目没有商店自动更新。

## 隐私与权限

- 不连接工作台、钉钉、ERP或另一个报表服务器，不上传报表到本项目服务端；导出依赖平台官方页面和浏览器。
- 最近下载只保留插件任务识别的报表，最多30条，记录ID、本地路径和结束时间，不保存完整下载链接。
- 升级清空旧版宽范围最近下载记录，不删除下载文件、浏览器下载历史或店铺设置。
- 为判断任务是否下载完成，仍会有界查询近期下载元数据，不能理解为浏览器下载记录完全不可见。
- `downloads`用于下载识别及命名；`alarms`用于定时；`storage`用于配置与日志；`tabs`、`activeTab`、`scripting`用于官方页面交互；`debugger`用于可信页面点击。
- 当前仍保留淘宝、阿里妈妈子域授权，以兼容旧流程与跳转，未宣称已做到最小权限。

运行日志及报表可能包含经营信息。反馈问题前请遮挡店铺、金额、商品和下载链接，勿上传真实报表或账号凭据。

## 常见问题

**提示任务正在运行？** 等当前任务完成。暂停不是取消已提交的官方导出；不确定是否下载时先看浏览器下载记录，避免重复提交。

**淘宝联盟没有入口或无法导出？** 请使用商家账号进入推广概览，确认账号报表权限。不能用联盟推广者账号替代。

**页面改版、验证或频控怎么办？** 停止任务，人工处理后再继续。插件不保证免风控，也不保证无人值守。

## 版本与边界

当前版本 **1.2.3**，包含专属图标、淘宝联盟推广概览、官方原名CSV完成识别及下载记录隐私优化。用户已反馈淘宝联盟单日下载和历史补采可用。不同电脑、账号权限、跨月文件内容、实际定时和旧五类报表仍可能存在差异，不作全场景保证。
